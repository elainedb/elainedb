# Hi, I'm Elaine 👋

Mobile developer. I build for **Android (Kotlin)**, **Flutter**, and **React Native**, and I've shipped several small apps to the Play Store and TestFlight.

Lately I've been running side-by-side experiments: the same app spec, built from scratch by different AI coding agents on different mobile stacks, to see where each one shines and where it falls over.

## 🔬 AI coding agent experiments

**[ai-agents-face-off](https://github.com/elainedb/ai-agents-face-off)** · The same app spec, handed to different AI coding agents, on Android, Flutter, and React Native. Each cell is an independent implementation; intermediate runs and model variants are preserved as tags.

| Round | Spec | Agents | Stacks |
|---|---|---|---|
| [2026 · ytdash](https://github.com/elainedb/ai-agents-face-off/tree/main/2026-ytdash) | Google Sign-In, YouTube feed, caching, filters, map, perf monitoring, in 5 versions | Claude Code · Gemini · Codex | Android · Flutter · React Native |
| [2025 · login-feed](https://github.com/elainedb/ai-agents-face-off/tree/main/2025-login-feed) | Google Sign-In with allowlist, YouTube video list | Claude Code · Gemini · Junie | Android · Flutter · React Native |

## 📱 Apps and projects

- **[Voice Clock](https://github.com/elainedb/flutter_voice-clock)** · Flutter · A digital clock you control with your voice, using Picovoice Porcupine for on-device wake-word detection. Built for the Flutter Clock challenge.
- **[Registry Helper for Wizards Unite](https://github.com/elainedb/flutter_registry-helper-for-wizards-unite)** · Flutter, Firebase · Companion app for Harry Potter: Wizards Unite, released on the Play Store and TestFlight with Cirrus CI and fastlane.
